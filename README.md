## เอกสารนี้คืออะไร?

เอกสารนี้คือ **แผนงานและข้อกำหนดโครงสร้าง** สำหรับระบบ "Hybrid AI Platform" — ระบบที่รับโจทย์จากผู้ใช้ ให้ AI วิเคราะห์ แยกแยะหลักฐาน เก็บข้อมูลดิบเป็นส่วนกลาง แล้วส่งต่อข้อมูลเป็นทอดๆ ผ่านหลายเฟส จนได้ผลลัพธ์สุดท้าย

**จุดเด่นของระบบนี้:**
- ไม่พึ่ง AI ตัวเดียวทำทุกอย่าง แต่แบ่งเป็นเฟส แต่ละเฟสมีหน้าที่ชัดเจน
- มี "ตัวตรวจสอบ" (Gate) แยกจาก "ตัวทำงาน" (Phase) — ห้ามตัวเองตรวจงานตัวเอง
- ทุกข้อมูลผ่าน "จุดผ่านเดียว" (Master Adapter) เพื่อกันข้อมูลผิดรูปแบบตั้งแต่ต้น
- ทุกการทำงานบันทึกเป็นเช็กลิสต์ (append-only) ทำให้หลายคนทำงานร่วมกันได้
- นำมาตรฐานจากองค์กรใหญ่ๆ มาประกอบ ไม่ประดิษฐ์ใหม่ทั้งหมด

## 5 หลักการหลักของระบบนี้ (จำให้ได้)
1. **Schema-first** — วางโครงสร้างข้อมูล/สัญญาให้จบก่อน แล้วค่อยรวบรวมข้อมูล
2. **Adapter ต่อเฟส** — แต่ละเฟสมีแม่แบบของตัวเอง รู้ input/output/แหล่งข้อมูลที่ต้องหยิบ
3. **Gate อิสระ** — ตัวทำงาน (Phase) ห้ามตรวจงานตัวเอง ต้องมี Gate แยกมาตรวจสอบความสอดคล้องระหว่างเฟส 100%
4. **ไป-กลับได้ (Bidirectional)** — ทุกข้อมูลตรวจย้อนกลับไปต้นทางได้ และเดินหน้าจากจุดกึ่งกลางได้
5. **เช็กลิสต์บันทึกทุกอย่าง** — ก่อนเริ่มบันทึกแผน หลังทำเช็ครายการ บันทึกต่อเนื่อง ห้ามลบ record เก่า ทำให้หลายคนทำงานร่วมกันได้
